# Blower Controller

Aplicación para monitorear la temperatura y controlar la velocidad de un blower de forma remota desde el teléfono.

## Funciones

- Muestra la temperatura en tiempo real con un decimal
- Control de velocidad con 5 niveles: apagado y velocidades 1 al 4
- Modo **automático** — el sistema electrónico decide la velocidad
- Modo **manual** — tú decides la velocidad desde la app
- Indicador de conexión en tiempo real
- Instalable como app en tu teléfono (sin tienda de aplicaciones)
